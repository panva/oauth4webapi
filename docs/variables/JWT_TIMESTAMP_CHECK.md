• `const` **JWT\_TIMESTAMP\_CHECK**: `"OAUTH_JWT_TIMESTAMP_CHECK_FAILED"` = `'OAUTH_JWT_TIMESTAMP_CHECK_FAILED'`

Assigned to [OperationProcessingError.code](../classes/OperationProcessingError.md#code).
